# Bases de Dados

As bases de dados constituem um dos principais insumos para o monitoramento estratégico realizado pela AHCS, permitindo compreender diferentes aspectos da atuação das Controladorias Setoriais e Seccionais, identificar padrões, situações que demandem atenção e subsidiar o acompanhamento e a tomada de decisão.

Esta seção apresenta, de forma individualizada, as principais bases utilizadas pela Assessoria, contemplando suas características, conteúdo, formas de acesso, possibilidades de utilização e limitações.

## O que são bases de dados

No contexto do monitoramento estratégico, as bases de dados correspondem a conjuntos estruturados de informações provenientes de sistemas, instrumentos de planejamento, registros administrativos e outras fontes.

Cada base possui características próprias quanto à origem, estrutura, periodicidade de atualização e nível de detalhamento das informações.

## Como a AHCS utiliza as bases

A Harmonização utiliza as bases de dados para observar aspectos relacionados à estrutura das unidades, ao planejamento, à execução das atividades e a outros aspectos relevantes para o monitoramento estratégico.

Conforme a finalidade da análise, as bases podem ser utilizadas de forma individual ou integrada. A integração, quando necessária, permite complementar informações, confrontar registros e construir uma visão mais abrangente da atuação das unidades.

## Pontos de atenção

A utilização das bases deve considerar as características e limitações de cada fonte de informação.

Entre os principais aspectos a serem observados estão a atualidade dos dados, o período de referência e a periodicidade de atualização.
