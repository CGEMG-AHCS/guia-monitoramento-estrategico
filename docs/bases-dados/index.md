# Bases de Dados

As bases de dados constituem um dos principais insumos para o monitoramento estratégico realizado pela AHCS. A utilização integrada dessas informações permite ampliar a compreensão sobre a atuação das Controladorias Setoriais e Seccionais, identificar situações que demandem acompanhamento e subsidiar análises e tomadas de decisão.

Esta seção apresenta as principais bases utilizadas pela AHCS, sua finalidade no processo de monitoramento e os cuidados necessários para uma utilização adequada das informações.

## O que são bases de dados

No contexto do monitoramento estratégico, as bases de dados correspondem a conjuntos estruturados de informações provenientes de sistemas, instrumentos de planejamento, registros administrativos e outras fontes utilizadas para acompanhar a atuação das Cset/Csec.

Cada base possui características próprias quanto à origem, estrutura, periodicidade de atualização e nível de detalhamento das informações.

## Como a AHCS utiliza as bases

A AHCS utiliza as bases de dados como fontes de informação para subsidiar o acompanhamento das unidades, possibilitando a observação de aspectos relacionados à estrutura, ao planejamento, à organização e à execução das atividades.

A análise integrada dessas informações contribui para a identificação de padrões, situações que demandem atenção e outros elementos relevantes para orientar e priorizar o monitoramento estratégico.

## Integração entre as bases

As bases não devem ser analisadas de forma isolada. Sempre que possível, as informações provenientes de diferentes fontes são relacionadas e analisadas conjuntamente.

A integração permite complementar informações, confrontar registros e construir uma visão mais abrangente sobre cada unidade, fortalecendo a qualidade das análises realizadas pela AHCS.

## Cuidados na utilização

A utilização das bases deve considerar as características e limitações de cada fonte de informação.

Entre os principais aspectos a serem observados estão a atualidade dos dados, o período de referência e a periodicidade de atualização.

Por essa razão, os dados devem ser observados considerando seu contexto e, quando necessário, complementados por outras fontes de informação.

## Bases disponíveis

Nesta seção são apresentadas as bases utilizadas no monitoramento estratégico, com orientações sobre seu conteúdo e sua utilização:

- **Estrutura das Unidades**: composição e organização das Controladorias Setoriais e Seccionais;
- **PACI**: planejamento das atividades das unidades;
- **RACI**: registro das atividades realizadas;
- **Manifestações**: manifestações de ouvidoria recebidas e tratadas pelas unidades **em elaboração**;
- **e-CGU**: atividades e registros mantidos no sistema, utilizados de forma complementar no acompanhamento da atuação das unidades.
