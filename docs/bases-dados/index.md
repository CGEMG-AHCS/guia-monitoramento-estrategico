# Bases de Dados

As bases de dados constituem um dos principais insumos para o monitoramento estratégico realizado pela AHCS.

Conforme a finalidade da análise, as informações podem ser utilizadas de forma individual ou integrada, permitindo compreender diferentes aspectos da atuação das Controladorias Setoriais e Seccionais e subsidiar o acompanhamento e a tomada de decisão.

A consolidação dessas informações possibilita, ainda, uma visão mais abrangente da atuação das unidades descentralizadas nos órgãos e entidades.

Esta seção apresenta as principais bases utilizadas pela AHCS, organizadas de forma individualizada, com informações sobre suas características, conteúdo, formas de acesso, possibilidades de utilização e limitações.

## O que são bases de dados

No contexto do monitoramento estratégico, as bases de dados correspondem a conjuntos estruturados de informações provenientes de sistemas, instrumentos de planejamento, registros administrativos e outras fontes utilizadas para acompanhar a atuação das Cset/Csec.

Cada base possui características próprias quanto à origem, estrutura, periodicidade de atualização e nível de detalhamento das informações.

## Como a AHCS utiliza as bases

A Assessoria utiliza as bases de dados como fontes de informação para subsidiar o acompanhamento das unidades, possibilitando a observação de aspectos relacionados à estrutura, ao planejamento e à execução das atividades.

A análise dessas informações contribui para a identificação de padrões, situações que demandem atenção e outros elementos relevantes para orientar o monitoramento estratégico.

## Integração entre as bases

As bases podem ser utilizadas de forma individual ou integrada, conforme a finalidade da análise.

A integração permite complementar informações, confrontar registros e construir uma visão mais abrangente, fortalecendo a qualidade das análises realizadas.

## Pontos de atenção

A utilização das bases deve considerar as características e limitações de cada fonte de informação.

Entre os principais aspectos a serem observados estão a atualidade dos dados, o período de referência e a periodicidade de atualização.

Por essa razão, os dados devem ser interpretados considerando seu contexto e, quando necessário, complementados por outras fontes de informação.
