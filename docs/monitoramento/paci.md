# Plano Anual de Controle Interno — PACI

O **Plano Anual de Controle Interno (PACI)** é o instrumento de planejamento que organiza as ações de controle interno a serem realizadas pelas Controladorias Setoriais e Seccionais ao longo do exercício.

No âmbito das Controladorias, o acompanhamento do PACI permite verificar o desenvolvimento das ações planejadas, identificar eventuais desvios ou necessidades de ajuste e acompanhar os resultados alcançados.

## O que deve ser acompanhado

O monitoramento do PACI deve considerar, especialmente:

* as ações previstas no plano;
* o estágio de execução das atividades;
* os prazos estabelecidos;
* os resultados e produtos entregues;
* eventuais dificuldades ou alterações ocorridas durante a execução;
* as providências adotadas para o tratamento das situações identificadas.

Nesta seção serão disponibilizadas orientações práticas para o acompanhamento do PACI, incluindo os procedimentos, registros e informações necessários ao monitoramento das ações.
