# Utilização Integrada das Bases de Dados

## Apresentação

Cada base de dados apresenta uma perspectiva específica das Controladorias Setoriais e Seccionais.

Embora individualmente permitam responder diferentes questões gerenciais, a utilização integrada dessas fontes amplia significativamente a capacidade analítica do monitoramento estratégico.

## Pergunta X

A unidade possui estrutura compatível com as atividades que executa?

### Bases recomendadas

- Estrutura da Unidade
- RACI
- RACI

### Possíveis análises

- Quantidade de servidores;
- Perfil técnico da equipe;
- Competências atribuídas;
- Quantidade de atividades realizadas.
